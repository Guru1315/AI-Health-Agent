# AI Health & Fitness Planner

A Streamlit app that turns a short profile (age, height, weight, goals and so on) into a one-day meal plan and a workout routine, then lets you ask follow-up questions about them. Two AI agents, built with the [Agno](https://github.com/agno-agi/agno) framework and powered by Google Gemini, write the plans.

> **Not medical advice.** The plans are generated by an AI model and have not been reviewed by a doctor, dietitian or trainer. Check them with a qualified professional before changing your diet or starting a new exercise routine, especially if you have a medical condition.

## Features

- Profile form with age, height, weight, sex, activity level, dietary preference and fitness goal
- **Dietary Expert** agent: a day of meals (breakfast, lunch, dinner and snacks) for your profile
- **Fitness Expert** agent: a routine with warm-up, main workout and cool-down, with the benefit of each exercise explained
- Follow-up questions about your plans, with a Q&A history shown on the page
- Your Gemini API key is entered in the sidebar and is not saved to disk

## Get an API key

Create a Gemini API key at https://aistudio.google.com/apikey. The app does not work without one.

## Run it

```bash
git clone https://github.com/Guru1315/AI-Health-Agent.git
cd AI-Health-Agent
pip install -r "requirements (health).txt"
streamlit run health_agent.py
```

The requirements file has spaces and brackets in its name, so keep the quotes around it. Streamlit opens the app in your browser (usually http://localhost:8501).

## How to use it

1. Paste your Gemini API key into the **API Configuration** box in the sidebar.
2. Fill in your profile. The number fields start at their lowest allowed value, so set age, height and weight before generating.
3. Click **Generate My Personalized Plan**. Both agents run, one after the other, and the plans appear in two panels.
4. Type a question under **Questions about your plan?** and click **Get Answer**. Questions and answers stack up under **Q&A History**.

| Height | 100 to 250 cm |
| Weight | 20 to 300 kg |

## How it works

- `health_agent.py` is the whole app. It builds one Gemini model and creates the agents when you click generate.
- The **Dietary Expert** and **Fitness Expert** agents each receive your profile as text and return their plan. The meal plan and the exercise routine are the model's output.
- A third, general agent answers follow-up questions. It is given your current meal plan, your routine and your question.
- Plans, answers and history are kept in Streamlit's session state, so they disappear when you refresh the page.

### What is AI-written and what is fixed

Only the meal plan, the exercise routine and the Q&A answers come from the model. The side panels are fixed text that is the same for every user:

- "Why this plan works" (high protein, healthy fats, moderate carbohydrates, caloric balance)
- "Important Considerations" (hydration, electrolytes, fiber, listening to your body)
- "Goals" (build strength, improve endurance, maintain overall fitness)
- "Pro Tips" (track progress, rest, form, consistency)

So the "Why this plan works" text will not change even if you pick, say, Keto or Lose Weight.

## Notes and limits

- The model is set in one place in `health_agent.py`, as `gemini-3.6-flash-preview-05-20`. Preview model names can be retired. If you get a model error, change that ID to one your key can use.
- The Q&A agent is created with `debug_mode=True`, so extra debugging output is written to the terminal where Streamlit is running.
- No tests, and no handling of conditions such as pregnancy, allergies, injuries or medication. The dietary preference is a single choice, so you cannot combine, for example, Vegetarian and Gluten Free.
- Never commit your API key. The app asks for it in the browser, so it does not need to live in the code.
